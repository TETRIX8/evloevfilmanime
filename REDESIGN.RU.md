# Evloev Film — обновлённый интерфейс

Исходная база: https://github.com/TETRIX8/evloevfilmanime
Ветка: main. Исходный commit: f4fc763d658c97c983df89d020370cb7de9fd809.

Это изменённая копия исходников, а не опубликованный сайт и не изменения в GitHub.

## Что изменено

- Новая главная: авторская AI-иллюстрация вечернего города, большой первый экран, категории, подборки, блок личной библиотеки.
- Единая светлая/тёмная палитра с переключателем. Начальная тема определяется Flowbite и настройками браузера; сохранённый выбор сохраняется штатным механизмом Flowbite.
- Новые шапка, меню аккаунта и мобильная нижняя навигация. На страницах входа и создания аккаунта нижняя панель скрыта, чтобы не перекрывать форму.
- Новые карточки постеров, читаемые названия под обложками, статусы и заглушка при недоступном изображении.
- Подборки прокручиваются нативно, доступны с клавиатуры; кнопки управляют только своей подборкой.
- Новая форма входа: показ/скрытие пароля, необязательное «Запомнить меня», блокировка повторной отправки, понятная ошибка, проверка внутреннего redirect.
- Новая страница /register: честное объяснение и переход в официальный Anixart. Это НЕ форма веб-регистрации и НЕ backend создания пользователей.
- Новый загрузчик: анимированный знак, кольца, неопределённый индикатор и плавное исчезновение. Нет случайных SSR-частиц и выдуманных процентов. Начальная заставка ожидает восстановление настроек/сессии, а данные каталога имеют отдельные скелетоны. Убрана старая обязательная многосекундная анимация.
- Учитывается prefers-reduced-motion, добавлены ссылка пропуска навигации, явный фокус, подписи полей и уведомления об ошибках.
- Подборки главной загружаются параллельно; предусмотрены недоступный API, повтор загрузки и пустой каталог.
- Исправлены передача тела form-urlencoded, порядок удаления параметра API-Version в прокси, мутация общих заголовков, кодирование логина/пароля и чтение повреждённой записи JWT.

## Что ещё НЕ сделано

1. **Регистрация внутри сайта.** В исходниках не найден подтверждённый контракт регистрации Anixart: endpoints, подпись, подтверждение email, captcha, ответы и ошибки. Неподтверждённые запросы не добавлены. Чтобы завершить эту часть, нужен контракт API Anixart либо решение использовать отдельные аккаунты Evloev Film с собственной БД и серверной авторизацией. Собственные аккаунты сами по себе не дадут доступа к аккаунту Anixart.
2. Не переделаны индивидуально все существующие страницы: профиль, редактор коллекций, комментарии, настройки и внутренности плеера сохраняют исходную структуру. Общие шапка, тема и карточки обновлены. Это значительное обновление основных экранов, не заявление о полной переработке каждой страницы.
3. Нет публикации в GitHub/Vercel и нет развёртывания сервиса player-parser. Удалённый репозиторий не менялся.
4. Реальный вход, создание аккаунта, операции с пользовательскими данными и воспроизведение не проверялись с настоящим аккаунтом. UI входа проверен искусственными ответами API; каталог и открытие страницы релиза проверялись анонимно.
5. Это не полный аудит безопасности. Исходный протокол Anixart по-прежнему использует параметры URL при входе, а сохранённый токен хранится в localStorage. Не логируйте query-параметры авторизации в reverse proxy/аналитике, используйте HTTPS. Переход на серверную HttpOnly-сессию требует отдельного проектирования и проверки совместимости.

## Запуск

Используйте совместимую поддерживаемую версию Node.js. Сборка этой копии проверена на Node.js 24.

```bash
npm ci
npm run dev
```

Откройте http://localhost:3000.

Production:

```bash
npm ci
npm run build
npm run start
```

Если нужны свои адреса сервисов, скопируйте `.env.sample` в `.env.local` и заполните значения. Для обычного запуска используется встроенный API-прокси; для встроенного пользовательского плеера нужен отдельный `NEXT_PUBLIC_PLAYER_PARSER_URL`. Не помещайте секреты в `NEXT_PUBLIC_*`.

`npm run dev-with-services` не является автономным запуском: скрипт ожидает отдельные папки `player-parser` и `api-prox`, которых нет в этой исходной базе. Для проверки интерфейса используйте `npm run dev`.

На Vercel импортируйте именно ваш репозиторий с этими изменениями. Старые инструкции DEPLOYMENT.RU.md содержат ссылки на другой upstream; команды клонирования оттуда не относятся к этой копии.

## Как применить к своему репозиторию

Сделайте резервную копию/ветку. В комплекте есть полный проект и binary patch. Patch рассчитан на указанный выше исходный commit:

```bash
git switch -c redesign/evloev-film
git apply --check /path/to/evloev-redesign.patch
git apply /path/to/evloev-redesign.patch
npm ci
npm run build
```

Если main уже изменился, не заменяйте исходники вслепую: перенесите изменения с разрешением конфликтов. Свою `.env.local` сохраните отдельно; в архиве её нет. Полный проект можно использовать независимо от patch.

- Chromium: 1440 px, 1024 px, 390 px; основные экраны светлой и тёмной темы.

- Визуальные снимки основных состояний. Это не исчерпывающий end-to-end тест всех страниц и не аудит WCAG.
